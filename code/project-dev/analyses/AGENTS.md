# Analysis subtree rules

Use `.agents/skills/empirical-march/SKILL.md` for every numbered analysis and `.agents/skills/scientific-figures/SKILL.md` for every figure.

- One numbered folder answers one main question.
- Write `notes/plan.md` and the success/failure rule before expensive or confirmatory work.
- Search prior folders and cluster outputs before launching duplicates.
- Put scripts, results, figures, notes, and the report in the owning folder.
- Update `notes/STATE.md` at every material transition.
- Every reported number must trace to a result file and every result figure to a script.
- Failed or stopped work remains documented.
- Create a new numbered folder when the question changes; create a new take when the project's organizing frame changes.
- Promotion into `preprint_figures` is a separate curation step, not a reason to delete analysis history.
