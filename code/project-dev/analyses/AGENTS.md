# Analysis rules

Use `.agents/skills/empirical-march/SKILL.md` for every numbered analysis and `.agents/skills/scientific-figures/SKILL.md` for every figure.

- Each numbered folder answers one main question.
- Write `notes/plan.md` and the pass/fail rule before any expensive or confirmatory run.
- Check earlier folders and cluster outputs before launching something that may already exist.
- Keep scripts, results, figures, notes, and the report in the analysis's own folder.
- Update `notes/STATE.md` whenever something important changes.
- Every reported number must come from a result file, and every figure from a script.
- Failed or stopped work stays documented.
- Make a new numbered folder when the question changes. Start a new take when the project's main question changes.
- Moving a result into `preprint_figures` is a separate step, and is never a reason to delete analysis history.
